菜價計算機 PWA 部署步驟(GitHub Pages)
════════════════════════════════════════

【上線】
1. 把這個資料夾裡的「所有檔案」上傳到 repo 根目錄(不要連資料夾一起丟):
   index.html / manifest.json / sw.js / icon-180.png / icon-192.png / icon-512.png
2. 記得按 Commit changes
3. Repo → Settings → Pages → Deploy from a branch → main /(root)
4. 等 1~2 分鐘,網址:https://你的帳號.github.io/repo名/

【裝到 iPad】
5. 用 Safari 打開網址(第一次要有網路)
6. 分享 →「加入主畫面」→ 主畫面出現綠色「菜」icon
7. 點 icon 開一次,讓離線快取裝好

【日後更新】
改好 index.html 後 push 即可,媽媽有網路時開 app 會自動更新。
若改了 icon 或 manifest,把 sw.js 裡的 CACHE 版本號 'vpc-v2' 往上加一號再 push。

【注意】
‧ 品項、分類、客戶記憶、未結清都存在 iPad 這個主畫面 app 裡,不會上傳任何伺服器。
‧ 刪除主畫面 icon = 刪除所有資料,請提醒媽媽不要隨意刪。
